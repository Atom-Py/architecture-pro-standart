# Крупные задачи по системам

Список составлен по решениям из ADR третьего задания (MVP подачи заявки на депозит) и ADR четвёртого задания (передача ставок в кол-центры). Коды задач используются в дорожной карте.

Тип задачи: **MVP** - входит в первые 6 месяцев, **Ставки** - изменения из нового кейса, тоже внутри MVP, **Целевое** - относится к состоянию через год.

## АБС

| Код | Задача | Тип | Зависит от | Результат |
|-----|--------|-----|------------|-----------|
| A1 | Модуль ведения ставок: модель данных, сетки по срокам и суммам, экранные формы, роли и разграничение доступа между бэк-офисом депозитов и бэк-офисом кредитов | MVP | - | Ставки ведутся в системе, а не в файле Excel |
| A2 | Процесс согласования индивидуальной ставки по заявке внутри АБС | MVP | A1 | Согласование без переписки по электронной почте |
| A3 | Таблицы обмена и публикация событий: исходящие события по ставкам и статусам, приём входящих заявок | MVP | A1 | АБС отдаёт изменения наружу и принимает заявки из digital-каналов |
| A4 | Доработка модуля обработки заявок на депозит: очередь заявок из digital-каналов, подтверждение условий, открытие депозита | MVP | A3 | Бэк-офис обрабатывает онлайн-заявки в привычном рабочем месте |
| A5 | Автоматическое подтверждение ставки и открытие депозита без участия бэк-офиса | Целевое | A4 | Депозит открывается без сотрудника |
| A6 | Оформление депозита в отделении силами только фронт-офиса | Целевое | A5 | Бэк-офис исключён из процесса в отделении |

| Код | Задача | Тип | Зависит от | Результат |
|-----|--------|-----|------------|-----------|

| P2 | API Gateway: маршрутизация, TLS, ограничение частоты запросов, проверка сессии клиента | MVP | - | Единая точка входа для сайта и интернет-банка |
| P3 | Сервис депозитных продуктов: витрина ставок и расчёт персональных ставок | MVP | P1, P6 | Каналы получают ставки, не обращаясь к АБС |

| P8 | Контроль доставки, метрики, оповещения, сквозной идентификатор операции | Ставки | P7 | Сбой публикации обнаруживается автоматически |
| P9 | Автоматическое оформление депозита без участия бэк-офиса | Целевое | P4, A5 | Полностью автоматический сценарий открытия |
| P10 | Расширение платформы под кредитные заявки и предодобренные предложения | Целевое | P4 | Основа для кредитного процесса из пятого задания |
